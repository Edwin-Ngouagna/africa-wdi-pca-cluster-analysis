# PCA and Cluster Analysis of Africa's World Development Indicators

## Project Overview
This project applies Principal Component Analysis (PCA) and Cluster Analysis to World Development Indicators (WDI) from 54 African countries to explore patterns and similarities in their development profiles.

## Objectives
- Reduce multiple development indicators into fewer dimensions using PCA.
- Identify groups of countries with similar development characteristics.
- Examine Cameroon's position in relation to countries with similar profiles.

## Methodology
- Data cleaning and missing-value assessment
- Median imputation
- Data standardisation
- Correlation analysis
- Principal Component Analysis (PCA)
- Cluster Analysis
- Country-level comparative analysis

## Programming Language
**R**

## Key Findings
- Four principal components explained 54.05% of the total variance.
- The analysis explored a five-cluster solution.
- Cameroon was grouped with 19 other African countries in Cluster 5.
