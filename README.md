# PCA and Cluster Analysis of World Development Indicators across 54 African Countries

## Project Overview

This project applies Principal Component Analysis (PCA) and Cluster Analysis to World Development Indicators (WDI) from 54 African countries.

The study explores patterns and similarities across African countries using selected indicators covering socioeconomic development, health, education, demographics, the environment, and governance.

## Objectives

- Explore the structure and relationships among selected development indicators.
- Apply PCA to reduce the dimensionality of the dataset.
- Use cluster analysis to identify groups of countries with similar development characteristics.
- Interpret the resulting patterns in the context of development across Africa.

## Methodology

The analysis follows these main steps:

1. Data preparation and assessment of missing values.
2. Missing-data treatment using median imputation.
3. Standardisation of indicators using R.
4. Principal Component Analysis (PCA).
5. Cluster Analysis.
6. Interpretation and reporting of findings.

## Tools and Technologies

- R Programming Language
- Principal Component Analysis
- Cluster Analysis
- Data Cleaning and Preparation
- Statistical Analysis and Visualisation
